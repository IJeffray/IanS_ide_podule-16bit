# ide podule 16 bit - software

Settype to Basic and run (set the current dir to wherever you have stored your rom image will make it easier to use)

Rudimentary software to program the flash in-situ in the machine. 

Has been used many times to program podules I've made, but use at your own risk.

(The same software is compatible with the 8 & 16 bit podules, but is different to the CH376 USB programming software)
